# Тренажёр горячих клавиш CAT-редактора

Учебный тренажёр горячих клавиш веб-редактора Phrase TMS: макет редактора с договором (DE → RU) и панель тренировки — отработка, уровни, режимы на скорость, задания на макете.

Открывается в браузере: https://slipfan3301.github.io/shortcut-trainer/ — ничего устанавливать не нужно. Прогресс хранится в браузере.
